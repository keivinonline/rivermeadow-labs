# 3. Source Inventory

---

Note down the private IPs of the deployed EC2 instances.

![](/img/rivermeadow_add_sources_1.png)

Add the source server via the Rivermeadow GUI and fill in the details:

- `source IP`
- `Useful tag`
- `new move group`
- tick the checkbox for `Source has preinstalled agent`
![](/img/rivermeadow_add_sources_2.png)

Repeat the process for the other EC2 server.
![](/img/rivermeadow_add_sources_3.png)

Once done, click on `Inspect and Migrate` to begin the migration process
![](/img/rivermeadow_add_sources_4.png)
