# 1.1 Compute Setup - Walkthrough

---

In this exercise you'll walk through creating the networking and compute resources which will be used throughout the workshop.

### Deployment

Download and save the YAML file from the pre-requisites page.
Upload the template file to create a new stack

![](/img/rivermeadow_cf_compute_1.png)

Set a stack name and select a desired VPC CIDR range that does not clash with existing resources
![](/img/rivermeadow_cf_compute_2.png)

Keep all the default values and agree to the acknowledgement box at the bottom of step 3.
![](/img/rivermeadow_cf_compute_3.png)

Press "submit" to start creating the stack
![](/img/rivermeadow_cf_compute_4.png)
